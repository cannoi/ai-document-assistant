# AI Document Assistant

AI Document Assistant is an application that helps users upload and analyze documents. The application can summarize content, answer questions, and search for information in documents efficiently.

## Features

- Upload documents
- Analyze documents
- Summarize content
- Answer questions
- Search information
- Store documents

## Installation

1. Clone the repository
2. Run `npm install`
3. Create a `.env` file based on `.env.example`
4. Run `npm start`

## Usage

1. Upload a document using the upload button
2. Use the features buttons to summarize, answer questions, or search for information
